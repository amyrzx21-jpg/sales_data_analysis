  Sales Data Analysis

  Overview
An exploratory sales data analysis project using Python and Pandas to identify sales patterns, product performance, customer behavior, and regional differences.

  Dataset
The dataset contains sales transactions with information including:
Order Date
Customer ID
Category
Product
Quantity
Unit Price
Region
Payment Method
Total Price

  Analysis
The project includes:
Data cleaning and preprocessing
Category and product performance analysis
Customer and regional analysis
Payment method analysis
Daily and monthly sales analysis
Quantity vs. total price correlation
Distribution and outlier analysis
Data visualization using Matplotlib and Seaborn

  Key Insights
Electronics generated the highest total sales revenue among categories.
Laptop was the highest-revenue product, generating approximately 1.79B in sales.
The correlation between quantity and total price was approximately 0.25, showing that quantity alone does not strongly explain revenue.
Among complete months, the fifth month had the highest sales and the second month had the lowest.
Monday had the highest sales among days of the week, while Sunday had the lowest.
Outlier transactions were identified using the IQR method.

  Tools
Python · Pandas · Matplotlib · Seaborn

  Conclusion
This project demonstrates an end-to-end exploratory data analysis workflow, from data cleaning to visualization and business insights.
